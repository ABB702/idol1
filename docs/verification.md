## 资源观察与限制

打包应用刚启动、未加载向量模型时，Electron 返回的工作集快照：Browser 147 MB、GPU 124 MB、Utility 47 MB、Tab 95 MB。此为一次启动快照，**未包含 Python sidecar**，共享内存也可能重复计算，不能视为整机额外占用或稳定空闲基准。Electron 的 GPU 进程用于界面渲染；本地向量模型明确使用 CPUExecutionProvider、2 线程。

本轮未做长期运行或 500 页完整采集压力测试，未给出 CPU、内存峰值和模型准确率保证。窗口关闭会停止后端；突然退出时运行中的更新会在下次启动标记中断。依赖安装目录在本次受限测试环境需要赋予 Chromium 应用沙箱读取权限；实际桌面测试使用正常 Windows 用户上下文完成，未关闭 Chromium sandbox。
